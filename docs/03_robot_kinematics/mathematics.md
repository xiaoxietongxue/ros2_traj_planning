# Phase 3 数学原理

本页解释正运动学、逆运动学、雅可比和可操作度。公式里的符号在第一次出现时给出含义。UR5e 的数值不在这里手算，由 `kinematics_demo` 用官方 URDF 算出来。

## 坐标系与齐次变换

一个刚体的位置和姿态可以写成 4×4 齐次变换矩阵：

\[
T =
\begin{bmatrix}
R & p \\
0 & 1
\end{bmatrix}
\]

- \(R\)：3×3 旋转矩阵，描述姿态。
- \(p\)：3×1 位置向量，单位米。
- 底下一行是三个 0 和一个 1。

绕单个关节转动时，相邻两个连杆之间有变换 \(T_{i-1,i}(q_i)\)。\(q_i\) 是第 \(i\) 个关节角，单位弧度。

## 正运动学

正运动学（Forward Kinematics，FK）回答：关节角已知时，末端在基座坐标系里在哪里。

\[
T_{0n}(q) = T_{01}(q_1)\, T_{12}(q_2)\, \cdots\, T_{n-1,n}(q_n)
\]

- \(q = [q_1,\ldots,q_n]^\top\)：全部关节角。
- \(n = 6\)：UR5e 的 `ur_manipulator` 有 6 个转动关节。
- \(T_{0n}\)：从模型根坐标系到末端的变换。本项目根坐标系是 URDF 的 `world`，末端连杆是 `tool0`。

本包不手写 DH 参数。`moveit::core::RobotState::getGlobalLinkTransform("tool0")` 按 URDF 把这 6 个变换乘起来。

### 两连杆数值例子

平面两连杆，每根长 \(L_1 = L_2 = 1\,\mathrm{m}\)，关节角 \(q_1 = 0\)，\(q_2 = \pi/2\)。末端位置是

\[
\begin{aligned}
x &= L_1\cos q_1 + L_2\cos(q_1+q_2) = 1 \\
y &= L_1\sin q_1 + L_2\sin(q_1+q_2) = 1
\end{aligned}
\]

UR5e 是同一件事的空间版本：每个关节贡献一个旋转，连乘后取出 `tool0` 的位置和旋转矩阵。

### 姿态的两种写法

旋转矩阵 \(R\) 有 9 个数，但只有 3 个自由度。程序里同时给出：

- `rotation`：3×3 矩阵。
- `orientation`：单位四元数 \((x,y,z,w)\)。\(q\) 和 \(-q\) 表示同一个姿态。

## 逆运动学

逆运动学（Inverse Kinematics，IK）回答：希望末端到达 \(T^\star\)，关节角应该是多少。

\[
q^\star = \mathrm{IK}(T^\star, q_{\mathrm{seed}})
\]

- \(T^\star\)：目标位姿。
- \(q_{\mathrm{seed}}\)：求解起点。UR5e 通常有多组解，种子决定收敛到哪一组。
- 求解器是 MoveIt 的 KDL 插件，不是解析解。它可能失败：目标在工作空间外，或种子离任何解都太远。

一致性检查不是比较 \(q^\star\) 和 \(q_{\mathrm{seed}}\) 是否相同，而是比较

\[
\| p(q^\star) - p_{\mathrm{target}} \|
\quad\text{和}\quad
\text{姿态夹角}
\]

本阶段验收要求位置误差小于 \(10^{-3}\,\mathrm{m}\)，姿态误差小于 \(10^{-2}\,\mathrm{rad}\)。用原始关节当种子时，实测两组误差都是 0。

## 速度与雅可比

末端速度和关节速度的线性关系是

\[
\dot{x} = J(q)\, \dot{q}
\]

- \(\dot{q}\)：6×1 关节速度，单位 rad/s。
- \(\dot{x}\)：6×1 末端速度。MoveIt 给出的矩阵是 **前 3 行平移（m/s），后 3 行转动（rad/s）**。
- \(J(q)\)：6×6 几何雅可比。参考点是 `tool0` 原点，表达在模型坐标系 `world`。

第 \(i\) 列是“只转动第 \(i\) 个关节时，末端怎样动”。腕关节轴线穿过 `tool0` 时，这一列的前 3 行接近 0：关节转了，但该点的位置几乎不动。

## 可操作度与奇异位形

Yoshikawa 可操作度：

\[
w(q) = \sqrt{\det\big(J(q)\, J(q)^\top\big)}
\]

- \(J J^\top\) 是 6×6 矩阵。
- \(w\) 大：末端在各个方向都还动得动。
- \(w \approx 0\)：至少有一个方向丢了，这就是奇异位形。

代码用特征值乘积计算行列式，避免接近 0 时出现负的舍入误差。

注意：\(J\) 的平移行单位是米，转动行单位是弧度，所以 \(w\) **不是无量纲量**。它只适合在同一台机器人、同一个参考点上比较大小，不能拿去和别的论文里的数值直接比。

本项目把 \(w < 10^{-3}\) 标成靠近奇异。这是工程阈值，不是定理。

实测（`kinematics_demo`）：

| 构型 | 关节角 (rad) | \(w\) |
|---|---|---|
| 普通 | `0.3 -1.0 1.2 -1.5 1.2 0.5` | 0.102818 |
| 腕部奇异 `wrist_2 = 0` | `0 -1.5708 1.5708 -1.5708 0 0` | 0 |

腕部奇异时，`wrist_1` 和 `wrist_3` 的轴线重合，雅可比降秩。

## 从公式到函数

| 公式 | 函数 |
|---|---|
| \(T_{0n}(q)\) | `computeFK` |
| \(q^\star = \mathrm{IK}(T, q_{\mathrm{seed}})\) | `computeIK` |
| \(J(q)\) | `computeJacobian` |
| \(w(q)\) | `computeManipulability` |
| 上面四项一起 | `evaluate` |
