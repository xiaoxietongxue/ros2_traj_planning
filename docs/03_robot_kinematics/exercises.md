# Phase 3 练习

在 `kinematics_demo` 已经跑通之后做。改完关节角要重新编译。

## 1. 改一个关节，看末端

把普通构型的 `shoulder_pan_joint` 从 `0.3` 改成 `0.7`，只改这一个数。

预期：位置会变，而且不是只改 z。`shoulder_pan` 绕竖直轴转，x 和 y 一起变。

## 2. 比较两个构型的可操作度

保留程序里的普通构型和 `wrist_2 = 0` 构型，把两次 `manipulability` 记下来。

预期：第二组明显更小。本仓库这次运行是 `0.102818` 和 `0`。你的打印应接近这两个数。

## 3. 找一个接近奇异的构型

从普通构型出发，只把 `wrist_2_joint` 改到 `0` 附近，例如 `0.05`、`0.01`、`0`。

预期：可操作度随着 `wrist_2` 靠近 0 而下降。降到 \(10^{-3}\) 以下时，程序会标 `near singularity`。

不要用超过关节限位的角度。`withinLimits` 会直接拒绝，FK 不会给你一个“凑合的”位姿。
