# Phase 5 数学：Minimum Jerk

## 优化问题

固定每段时间 \(T_i\) 和路径点位置。起点和终点的速度、加速度也固定。中间路径点的速度和加速度未知。

\[
\min \int_0^{T}\lVert q^{(3)}(t)\rVert^2 dt
\]

约束：

- 每段是五次多项式。
- 段与段之间位置、速度、加速度连续。
- 段端点的位置等于给定路径点。

这里的 \(\lVert\cdot\rVert^2\) 先对六个关节相加，再对时间积分。代码里每个关节单独优化，因为代价是各关节 jerk 平方之和，关节之间没有耦合。

## 和五次插值的差别

Phase 4 还多加了一条约束：中间路径点的速度和加速度必须是 0。Minimum jerk 没有这条约束，所以代价小于或等于“每段都停住”的五次多项式。只有一段时，两端状态已经把六个系数定死，两者相同。

## 怎么求

每个中间点有两个未知数：速度和加速度。一段多项式的 jerk 能量是这些边界量的二次函数。整条轨迹的 Hessian 是块三对角的：第 \(i\) 个路径点只和第 \(i-1\)、\(i+1\) 个点相邻。

块三对角系统可以用 Thomas 算法求解，计算量随段数线性增长。未知数不多时，这和直接分解整块矩阵的答案一致，但结构已经是后面 MINCO 要用的那种。
